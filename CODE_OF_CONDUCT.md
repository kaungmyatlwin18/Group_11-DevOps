# Code of Conduct

Group 11 members are expected to:

- Communicate respectfully with each other.
- Attend agreed meetings where possible.
- Complete assigned tasks on time.
- Use GitHub Issues and the project board to track work.
- Make regular commits with clear commit messages.
- Follow the agreed Git branching workflow.
- Discuss major changes before modifying another member's work.
- Inform the team if there are problems or delays.

If a disagreement cannot be resolved within the group, the team will contact the module teaching staff.
